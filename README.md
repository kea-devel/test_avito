# Модульный Парсер Товаров на Avito

Программа для автоматизированного сбора цен на товары по артикулам. Поддерживает два независимых режима работы: **Живая сессия (Online)** и **Локальный разбор сохраненных страниц (Offline)**.

## 🛠️ Развертывание проекта

Проект полностью настроен под декларативное управление зависимостями. Вы можете развернуть его любым удобным способом.

### Вариант А. Запуск через `uv` (Рекомендуется, на базе `pyproject.toml`)
1. Установите все зависимости проекта и автоматически создайте изолированное виртуальное окружение:
   ```bash
   uv sync
   ```
2. Инициализируйте бинарные файлы браузера для Playwright:
   ```bash
   uv run playwright install chromium
   ```
*Совет для VS Code: После выполнения `uv sync` менеджер создаст папку `.venv` в корне. Нажмите `Ctrl+Shift+P` -> `Python: Select Interpreter` и выберите интерпретатор из этой локальной папки `.venv`, чтобы Pylance сразу подхватил автодополнение.*

### Вариант Б. Классический запуск через `pip`
1. Создайте и активируйте ваше виртуальное окружение, затем установите пакеты:
   ```bash
   pip install -r requirements.txt
   ```
2. Установите браузер для Playwright:
   ```bash
   playwright install chromium
   ```

## 🚀 Варианты запуска

### Режим 1. Живой поиск (Online)
Скрипт открывает headless-браузер, вбивает артикулы в строку поиска и эмулирует действия пользователя.
```bash
python main.py -o tasks.json
```
*Формат входного файла `skus.json`: `["HONEX-101", "HONEX-102"]` (также поддерживается обычный текстовый файл .txt, где каждый артикул записан с новой строки).*

### Режим 2. Анализ слепков страниц (Offline)
Используется, если живой скрипт натыкается на блокировки анти-фрода или CAPTCHA. Вы можете сохранить страницы Avito вручную (через Ctrl+S) и передать их скрипту.
```bash
python main.py -f tasks.json
```
*Формат входного файла `tasks.json`:*
```json
[
  {
    "sku": 12312323,
    "file": "12312323.html"
  },
  {
    "sku": 32323232,
    "file": "32323232.html"
  }
]
```

## ⚙️ Реализация требований ТЗ и логика фильтрации
1. **Регион (Москва и МО)**: 
   - В *Online-режиме* фильтрация обеспечивается на уровне стартового URL ("https://www.avito.ru/moskva_i_mo`). 
   - В *Offline-режиме*, предполагается, что регион был выбран при формировании html. (Подключение сторонних API или создание дата-сетов для определения к какому региону относится тот или иной город считаю избыточным в рамках тестового задания)
2. **Состояние ("Новое")**: Скрипт пытается применить фильтр в интерфейсе Avito для отсечения б/у, но так же реализована логика по проверке через данные карточки (BadgeBar)
3. **Цена и Сортировка**: Объявления без числовой цены полностью исключаются. Фильтрация дублей, сортировка по возрастанию и срез ТОП-5 объявлений с присвоением мест выполняются средствами `Pandas`.

## ⏱️ Отчет о разработке
- **Фактически затраченное время**: около 5 часов (проектирование архитектуры, написание асинхронного лоадера). 
- **Сложности**: Не сразу понял как определять город. В итоге было принято решение изменить стартовую ссылку на "https://avito.ru/moskva_i_mo", что автоматически ограничивает поиск по нужному региону.
- **Использование ИИ**: ИИ применялся для генерации CLI (argparse), генерации readme.md.
